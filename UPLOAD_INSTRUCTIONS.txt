HOW TO ADD THESE FILES TO YOUR GITHUB REPO
==========================================

OPTION A — Drag & Drop (Easiest)
---------------------------------
1. Go to: https://github.com/OZAMNJ/WEMOS-D1-Mini-Travel-Router
2. Click "Add file" > "Upload files"
3. Drag ALL files/folders from this ZIP into the upload box
   (GitHub preserves folder structure automatically)
4. Scroll down, add commit message: "chore: add source code and community files"
5. Click "Commit changes"

OPTION B — GitHub Web Editor (for individual files)
-----------------------------------------------------
For each file, go to your repo and click "Add file" > "Create new file"
Then type the path + filename, e.g.:
  - src/router.ino
  - CONTRIBUTING.md
  - SECURITY.md
  - CODE_OF_CONDUCT.md
  - .github/ISSUE_TEMPLATE/bug_report.md
  - .github/ISSUE_TEMPLATE/feature_request.md
  - .github/pull_request_template.md

OPTION C — Git Command Line
----------------------------
1. Clone your repo: git clone https://github.com/OZAMNJ/WEMOS-D1-Mini-Travel-Router
2. Copy all files from this ZIP into the cloned folder
3. git add .
4. git commit -m "chore: add source code and community files"
5. git push

AFTER UPLOADING — Add Topics/Tags
-----------------------------------
1. Go to your repo main page
2. Click the gear icon next to "About"
3. Add these topics:
   esp8266, wemos-d1-mini, travel-router, nat-router, arduino,
   littlefs, iot, wifi-repeater, captive-portal, embedded

CREATING A GITHUB RELEASE
---------------------------
1. Go to: https://github.com/OZAMNJ/WEMOS-D1-Mini-Travel-Router/releases/new
2. Tag: v7.2.0
3. Title: v7.2 — LittleFS Persistent Storage
4. Description:
   ### What's New in v7.2
   - Persistent config storage via LittleFS
   - Custom DNS injection with pause/resume toggle
   - Hardware NAT via lwIP NAPT
   - Dark-mode async web dashboard at 192.168.4.1
   - NTP time sync (CEST)
   - Auto-reconnect loop every 15 seconds
   
   ### Flash Instructions
   Use the one-click web installer at: https://OZAMNJ.github.io/WEMOS-D1-Mini-Travel-Router
   
   ### Arduino IDE Settings
   - lwIP Variant: v2 Higher Bandwidth
   - Flash Size: 4MB (FS: 1MB)
5. Attach router.bin as a release asset
6. Click "Publish release"
